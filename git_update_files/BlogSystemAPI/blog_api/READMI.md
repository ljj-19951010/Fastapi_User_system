    <h2>项目介绍</h2>
    <ol>
      <li>功能介绍
        <p>该项目主要功能可以划分为两个，一个是对用户的管理操作，用户可以登录注册创建文章，而管理员用户可以对普通用户crud操作，也可以对用户的文章操作。第二个是文章的管理操作，用户未登录可以查看所有的文章，普通用户登录之后只能
        对自己的文章操作，不能修改其他人的文章，如果是管理员用户则可以操作所有的文章，比如删除文章
        </p>
      </li>
      <li>技术栈
        <p>基于FastAPI + SQLALCHEMY + MYSQL + REDIS等技术实现该API异步接口。通过SQLALCHEMY来对模型类的实现，和aiomysql的异步存储数据的实现，同时增加了REDIS的缓存技术，来增强项目的稳定性，控制了连接池pool的数量，
        以免过多用户访问时对项目造成阻塞。使用异步引擎对项目增强效率的同时，还能提高对数据库连接的速度。同时使用哈希密码，增强了用户密码的安全性。
        </p>
      </li>
    </ol>
