    <h2>项目介绍</h2>
    <ol>
      <li>功能介绍
        <p>使用该系统需要用户先注册和登录，所以第一个功能是用户的管理，实现对用户账户的crud操作，第二个功能则是对用户信息的管理，用户登录之后，可以查看自己的用户信息，比如：姓名、生日、住址等信息。同时可以对用户信息进行crud的操作，
          当然如果用户是普通用户只能对自己的信息操作，如果是管理员用户，可以对除了管理员以外的任何用户的账户和用户信息进行修改和删除等。
        </p>
      </li>
      <li>技术栈
        <p>基于FastAPI + SQLALCHEMY + MYSQL来完成的项目，主要使用了异步引擎和异步数据库aiomysql，增加项目的运行效率。用户验证我们使用了JWT技术，控制token缓存时间，实现登录接口，使用哈希密码来控制注册的密码，防止密码泄露，增强安全性。</p>
      </li>
    </ol>
